# Dastavez - AI Document Intelligence & Search Platform

Dastavez is an AI-powered document intelligence and multilingual RAG platform for indexing, processing, searching, and chatting with documents with full citation & source verification.

## Project Structure
- `backend/`: FastHTML + FastAPI + Python backend engine (RAG pipeline, document processing, semantic search)
- `frontend/`: React + Vite + Tailwind CSS frontend interface (Interactive Dashboard, Chat with Quick File Upload, Document Management, Analytics, OCR)

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
python -m venv venv
# Activate venv and install requirements
pip install -r requirements.txt
python main.py
```
